# xTerminal

## Introduction
This is mod to the original theme [re-terminal](https://github.com/mirus-ua/hugo-theme-re-terminal) by [Mirus](https://github.com/mirus-ua). The usage is kept intact but additional features are added.

The theme is solely tweaked with vibe-coding initially to well fit my own portfolio and is in the alpha state to make any prominent changes. I will try to maintain and sync to the original changes time to time.

Feel free to use, raise issues for contribution!
